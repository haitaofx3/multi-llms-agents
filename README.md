# 多 Agent 圆桌协作系统

一个支持多个 LLM Agent 围绕"圆桌"进行**辩论式多轮协作讨论**的 Web 项目。每个 Agent
拥有独立的基础模型、记忆系统、MCP 工具与上下文变量，由首位 Agent 担任**辩论主持人**进行
任务分派与追问，其余 Agent 立论、辩护、交锋并回报结果；讨论按设定轮次进行，主持人在
最后综合各方观点给出总结。

## 功能对照（需求 → 实现）

1. **环境变量**：读取 `.env`（本项目自带健壮解析器，兼容不规范写法）。
2. **多 Agent 对话**：支持 2–6 个 Agent 同时对话，分别可绑定 DeepSeek / Qwen / 自定义模型。
3. **共享向量库 + 记忆系统**：所有 Agent 共享同一向量知识库（Qdrant，不可用时降级为内存库）；
   每个 Agent 拥有 **短期 / 长期 / 情境（知识摘要）** 三类记忆，支持互相转化与可配置的遗忘机制。
4. **任务协作分配**：首个 Agent 为主 Agent，仅做任务分派（内容 + 期望效果）；
   协作 Agent 只回报最终结果与是否完成，**不反馈中间过程**。
5. **MCP 工具对象**：每个 Agent 拥有自己的 MCP 注册表，可"搜索工具"完成检索 / 联网 / 记忆回忆。
6. **上下文变量**：主 Agent 分派时提供"任务接收方变量"，协作 Agent 回填后反馈给分派方。
7. **多轮辩论**：讨论以"圆桌辩论"形式进行，轮次未达上限时持续多轮；主持人逐轮针对各方
   观点抛出疑问、要求论据、指出分歧（推动交锋），协作 Agent 进行辩护/反驳；所有 Agent
   均回报完成后不提前结束，而是继续辩论直至达到最大轮次。
8. **角色/性格约束**：对话严格遵循用户设定的角色与性格，除非用户修改。
9. **UI 界面**：圆桌游戏化界面，可配置角色/性格、发布讨论、暂停/结束，结果以 Markdown 保存。
10. **席位等分**：2 个 → 2 等分，3 个 → 3 等分，以此类推，按数量均匀分布。
11. **必填角色/性格**：未填写则按"机器人"角色带入。
12. **最大轮次收尾**：达到设定最大轮次后停止，由主持人综合所有轮次发言与任务结果，
   输出结构化的最终讨论总结。

## 运行

```bash
conda activate agent_env
python start.py
# 浏览器打开 http://localhost:8000
```

## 目录结构

```
config.py        环境变量与配置
llm.py           LLM 统一接入（OpenAI 兼容，含原生 function calling）
embeddings.py    本地句向量（sentence-transformers，带降级）
vector_store.py  共享向量知识库（Qdrant + 内存降级）
memory.py        每 Agent 记忆系统（短期/长期/情境 + 转化 + 遗忘）
tools.py         每 Agent 的 MCP 工具注册表
agent.py         Agent 定义（角色/性格/模型/记忆/MCP）
orchestrator.py  圆桌编排器（讨论、分派、回报、停止、暂停）
backend.py       FastAPI 后端 + WebSocket
static/          圆桌 UI（index.html / style.css / app.js）
discussions/     自动保存的 Markdown 结果
memories/        各 Agent 记忆持久化
```

## 使用流程

1. 设置 Agent 数量（2–6），逐个填写名称、角色、性格，选择基础模型（默认用 `.env`）。
2. 填写讨论主题 / 任务，设置最大轮次（可选注入共享知识）。
3. 点击"进入圆桌并开始讨论"，观察圆桌席位上的 Agent 轮流发言与任务流转。
4. 可随时 暂停 / 继续 / 结束；讨论完成或结束后可 导出 / 下载 Markdown 记录。
